# 📝 Notely

A simple, modern note-taking web app built with a clean TypeScript stack.  
Notely focuses on speed, minimalism, and ease of use — letting you jot down, organize, and manage your notes effortlessly.

---

## 🚀 Tech Stack

- **[Better Auth](https://better-auth.com/)** – Simple, secure authentication.
- **[Zod](https://zod.dev/)** – Type-safe schema validation.
- **[TypeScript](https://www.typescriptlang.org/)** – Strongly typed JavaScript.
- **[React Hook Form](https://react-hook-form.com/)** – Lightweight form handling.
- **[shadcn/ui](https://ui.shadcn.com/)** – Modern, accessible UI components.
- **[Drizzle ORM](https://orm.drizzle.team/)** – Type-safe database queries.
- **[Neon](https://neon.tech/)** – Serverless PostgreSQL hosting.
- **[Resend](https://resend.com/)** – Email sending (account verification, notifications).

---

## ✨ Features

- 🔐 Secure user authentication with **Better Auth**.
- 🗂️ Create, edit, delete, and organize notes.
- ✅ Form validation powered by **Zod** + **React Hook Form**.
- 🎨 Beautiful, accessible UI with **shadcn/ui**.
- 💾 Fast, serverless PostgreSQL via **Neon** + **Drizzle ORM**.
- 📧 Email verification and notifications with **Resend**.
